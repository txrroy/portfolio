Designing for Clarity at Scale

A unified design system that transformed a fragmented enterprise suite into a cohesive ecosystem, increasing user adoption by 40%.

[Hero Diagram / Interface Shot]
Role Lead Product Designer
Timeline 6 Months
Team 2 PMs, 4 Engineers
Platform Web & Mobile

The Challenge

The legacy platform suffered from years of feature bloat and inconsistent UI patterns. Users reported high cognitive load and difficulty navigating between core modules.

Our data showed that 65% of support tickets were related to "finding information" rather than functionality issues. We needed to simplify the architecture without removing critical power-user features.

Key Constraint

We could not rewrite the backend. All UX improvements had to be strictly frontend implementation on existing APIs.

Understanding the User

👷

The Operator

Focuses on efficiency and speed. Uses keyboard shortcuts and memorized paths.

  • Needs densified data views
  • Frustrated by "wizard" flows
👔

The Manager

Needs high-level overviews and reporting capabilities to track team progress.

  • Needs dashboard summaries
  • Values clean visualizations
🏗️

The Admin

Configures the system for others. Needs granular control over permissions.

  • Needs bulk edit tools
  • Prioritizes system stability

Iterative Design

Testing Assumptions

We started with rough paper prototypes to test the new navigation ontology. Early testing revealed that users struggled with the proposed "object-oriented" menu structure.

We pivoted to a "task-based" architecture, which aligned 40% better with user mental models in subsequent A/B testing.

"Simplifying the interface didn't mean hiding complexity, but organizing it intuitively."
[High Fidelity Interface - Dashboard]

Unified Dashboard

A centralized view that surfaces critical alerts and daily tasks, reducing the "morning hunt" for information by estimated 15 minutes per user.

[High Fidelity Interface - Mobile View]

Mobile-First Workflows

For the first time, field operators could complete critical approvals on-site, removing the bottleneck of returning to the office desktop.

Outcomes

Measurable Impact

Post-launch analytics verified that the redesign successfully aligned business goals with user needs.

+40%
User Adoption

Reflections

This project reinforced the importance of involving engineering early in the design process. The constraint of "no backend changes" sparked creative UI solutions that might not have emerged otherwise.

If I were to do this again, I would advocate for more robust accessibility testing earlier in the definition phase.
